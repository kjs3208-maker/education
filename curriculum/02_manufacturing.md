# 2부. 가스 소재 제조방법

## 목차: 전체 제조 프로세스 개관

원재료 공급 → 합성 → 정제 → 충전 → 품질분석 → 출하검사 (퓨어가스). 믹스가스는 정제 후 마더가스 생산 → 밸런스가스 믹싱 → 롤링 추가. 공통: 용기 준비(신규용기: 내면처리→세척→밸브삽입→가열배기 / 회수용기: 잔가스처리→가열배기).

## 2-1. 합성을 통한 제조

- **화학반응(HF 사례)**: 형석(CaF2)+황산 → HF가스+CaSO4 → 프리정제 → HF Condensation(액화) → 증류정제 → 흡착정제
- **열분해(SiH4 사례)**: 폴리실리콘 파우더+H2+SiCl4 → TCS 합성 → TCS열분해→DCS → DCS열분해→MCS → MCS열분해→SiH4. DCS·MCS 모두 별도 제품으로도 정제·판매. SiH4→Si2H6(디실란) 추가합성. 분리원리는 비점차이(SiCl4>TCS>DCS>MCS>SiH4 순 비점 감소).
- **전기분해**: 물 전기분해(H2/O2), 불소 전기분해(F2), 염소 전기분해(Cl2) — 양이온/음이온 분리로 이원자분자 생산.

## 2-2. 가스의 정제

- **정의**: 고체는 분별결정, 기체·액체는 흡착/증류/이온교환/여과
- **흡착(수소 PSA 사례)**: 물전기분해·원유분별증류·나프타분해·LNG합성 등에서 얻은 H2(순도~70%) → PSA(압력순환흡착, 흡착제: 몰레큘러시브+활성탄) → 5N(99.9%)
- **증류 정의**: 단순증류(끓는점 차이 뚜렷한 물질), 분별증류(끓는점 비슷한 다성분, 다단 증류탑)
- **증류 종류**: 상압증류(일반조건), 감압증류(저온 분리로 열분해 방지), 공비증류(제3물질로 공비혼합물 분리)
- **원유정제 사례**: CH4, C3H8, C4H10, C3H6, CO2, H2 등 부산물이 각각 정제되어 가스소재 원료로 재탄생
- **ASU(공기분리장치) 정의**: 공기 성분 비점차이로 초저온 증류(-185~187°C 운전). 벌크가스(N2,O2,Ar)는 사외생산+파이프공급+탱크백업. 희귀가스(Ne,Kr,Xe)는 제철소 O2용 ASU 부생가스에서 별도 컬럼으로 추출.
- **ASU 프로세스**: 공기압축 → 불순물제거(H2O,CO2,N2O) → 냉각(줄-톰슨효과) → 증류(콜드박스) → 배관공급+백업탱크
- **콜드박스 상세**: LP컬럼 내 트레이(위어·다운커머)에서 증기(N2 풍부, 상승)-액체(O2 풍부, 하강) 반복 접촉. 트레이 단수↑ → 순도↑·컬럼높이↑. 환류량↑ → 순도↑·생산량↓. 비점도표(O2 기준) 상 왼쪽으로 이동할수록 정제 진행.
- **ASU 희귀가스 회수 — Xe 사례** (`assets/2-2_ASU_Xe회수사례.pptx`): 대기중 Xe 농도 0.087ppm. Xe·Kr은 O2보다 끓는점이 높아 조 액체산소(Crude LOX)에 자연 농축 → 별도 Kr/Xe 농축컬럼에서 회수. 2022 우크라이나 전쟁으로 우크라이나발 Kr·Xe 공급망 충격(0부 네온 사례와 동일 시기·원인) → 각국 ASU에 회수설비 추가 움직임 확대.
- **달톤의 법칙**: 혼합기체 전체압력 = 각 성분 부분압력의 합. **라울의 법칙**: 혼합액체에서 각 성분 증기압 = 순수성분 증기압×몰분율. 트레이에서 질소가 산소보다 잘 증발(라울) → 증기 전체압력은 달톤으로 계산 → 트레이 반복될수록 증기엔 N2, 액체엔 O2 농축.

## 2-3. 가스 믹싱, 필터레이션

- **Mix Gas 용어**: 마더가스(주성분), 밸런스가스(희석), 프리믹스가스(최종충전 전 중간혼합) / **롤링**: 충전 후 균질화를 위해 굴리는 과정
- **여과**: 9LRV(0.003㎛ 이상 입자 10억개 중 1개만 통과) 표준. 필터소재: 소결금속(스테인리스·니켈·**하스텔로이**—Ni·Cr 함량 높아 내식성 우수), 테프론 멤브레인(저렴·호환성 좋으나 고압에 찢어질 위험 → 저압 설비용)
- **용기 전처리(신규용기)**: 외부검사 → 내부작업(배럴연마→DI워터세정→Hot N2건조) → 내부검사(조도검사) → 밸브장착 → 리크검사(가/감압+Snoop Test) → 잔가스처리(가열진공배기→RGA 잔류가스분석: H2O,O2,N2,CO2,THC,Ar 등 확인) → 도색 → 출하. **패시베이션**: 출하 전 실가스로 일부 채워 내부 분위기 조성.
- **충전(Filling)**: 압력법(압력 목표, 온도관리 중요) vs **중량법(무게 목표, 저울 검교정 중요, 실무 메인)**. He처럼 분자량이 매우 가벼운 가스는 중량법 자체가 안 되는게 아니라 고정밀 저울이 더 필요.
